Prompt the user for the temperature readings in Fahrenheit
Check the temperatures 1 by 1 to see if they are in the 68F to 76F range
If the Temperature is out the range display it as a WARNING status
If the temperature is in the range display it as NORMAL status
Add all temperatures up and divide by the total to get the average
save/write the temperatures and statuses to a file
If a temperature has a Warning status turn on the LED
If a temperature has a Normal status turn off the LED
Prompt the user and ask them if they would like to change the acceptable temperature range
set the temperature minimum and maximum to the new range.
